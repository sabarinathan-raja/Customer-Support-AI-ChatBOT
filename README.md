# Customer Support AI Chatbot

An AI-powered customer support chatbot built using Google Gemini API and Python.

## Features

- Customer support ticket classification
- AI-powered customer support responses
- Multiple support categories
- Google Gemini API integration
- Secure API key handling using Colab Secrets

## Customer Support Categories

- Payment Issue
- Refund Request
- Delivery Delay
- Account/Login Issue
- Product Issue
- Cancellation Request

## Technologies Used

- Python
- Google Gemini API
- Generative AI
- NLP
- Google Colab

## How to Run

1. Open the notebook in Google Colab.
2. Install the required Python packages.
3. Configure the Gemini API key using Colab Secrets.
4. Run the notebook cells.

## Project Overview

This project demonstrates how Generative AI can be used to automate
customer support ticket classification and provide AI-powered assistance.

## Security

The Gemini API key is stored securely using Google Colab Secrets
and is not included in the source code.
